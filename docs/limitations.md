# Limitations and future research

- This is a synthetic research prototype, not a legal compliance system or validated benchmark. A supported control judgment is a statement about supplied documentation, not verified practice, adequacy or a legal finding.
- Text Search matches configured terms; query prose is annotation context. Graph Search adds bounded traversal over recorded relationships. It does not infer entity alignment, invent missing targets, search the internet or inspect inaccessible documents.
- Graph gains depend strongly on curated source-grounded links. Their coverage, construction cost and error rate have not been evaluated on real corpora. More traversal does not fix a disconnected source, and candidate discovery is different from top-five success.
- All checked-in research reference expectations and exploratory labels are AI-authored. No independent human relevance reference exists. Repeated query variants are correlated; small synthetic splits do not establish population performance or probability calibration.
- The live study uses one model version and one response per case/configuration, with fixed baseline-then-alternative order. It does not measure repeatability, temporal drift or order effects. The held-out cases were written by the same AI researcher, so they are separate cases, not independent external validation.
- Vague human-control statements, queue timing and contradictory paragraphs expose unsettled category boundaries. Explicit reviewer uncertainty must remain available. Source-finding relevance can include a useful pointer without supporting the control.
- Recorded responses support offline replay. They do not guarantee the same output from a future paid repetition. Native probabilities and confidence are model outputs, not verified source truth.
- Browser storage has origin-specific capacity and no cross-device synchronization, authentication or durable multi-record transactions. Export before moving origins or clearing records. Latest-run evaluation can differ after label edits; exports preserve both request-time and current review snapshots.
- Assessment evaluation pools cases/models/definitions unless filtered; evidence evaluation requires an exact configuration group. An edited version name is insufficient without recorded content. Displayed metrics are descriptive agreement/error, not validated accuracy.
- API origin protection is not authentication, authorization or a spending budget. Public inference can consume the owner's balance. Cancellation may occur after the provider has processed a request. There is no reliable serverless in-memory rate limiter.

Next research priorities are independent full-pool review on new systems, assessment of graph-link coverage and curator effort, and a held-out test of a single preregistered ranking change. Do not tune question exceptions or relevance thresholds against the exposed cases. A model-assisted filtering stage remains unadopted because the live relevance judgments still promote a known editorial distractor.
